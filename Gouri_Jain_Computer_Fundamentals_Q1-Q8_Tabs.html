Five generations of computers

The generations are mainly distinguished by the hardware technology used.
First Generation

Vacuum Tubes

Approx. 1940s–1950s

Very large, hot, costly machines that consumed a lot of electricity.

ExamplesENIAC, UNIVAC I
Second Generation

Transistors

Approx. 1950s–1960s

Smaller, faster, more reliable, and more energy-efficient than vacuum-tube systems.

Key changeTransistors replaced vacuum tubes.
Third Generation

Integrated Circuits (ICs)

Approx. 1960s–1970s

Many electronic components were placed together on a small silicon chip.

Key changeSmaller size and improved performance.
Fourth Generation

Microprocessors

From 1970s onward

The CPU was placed on a single chip, enabling personal computers and laptops.

Key technologyVLSI — very-large-scale integration.
Fifth Generation

AI & Parallel Processing

Emerging / ongoing

Focuses on AI-based systems, parallel processing, and advanced chip integration.

Key focusULSI and AI-oriented technologies.

Q2. Functional Block Diagram of a Computer

Explain how data, instructions, and control signals move between the CPU, memory unit, and I/O interface.

🧠

CPU — Central Processing Unit

Executes instructions. The ALU performs arithmetic and logic; the Control Unit coordinates operations; registers hold immediate data and results.

Process + control
🗃️

Memory Unit

Stores programs, input data, intermediate values, and results. The CPU reads and writes memory using addresses and data signals.

Store + retrieve
🔌

I/O Interface

Connects peripheral devices to the computer and coordinates data transfer, device status, and control signals.

Peripheral communication

Functional data flow

Input device
Keyboard / scanner
→
I/O interface
Buffer + status
↔
Main memory
Data + instructions
↔
CPU
Fetch, decode, execute
→
Output device
Display / printer

Control signals coordinate memory reads/writes and I/O operations. Address signals identify a location or device; data signals carry the actual information. Results may be stored in memory or sent to output.

Instruction cycle

Fetch instruction from memory → Decode it in the Control Unit → Execute using the ALU/registers or I/O → Store the result if required.

Three signal types

Data: information transferred. Address: source or destination location. Control: operation to perform and when, such as read, write, or interrupt.

Exam point: The CPU is the processing and control centre; memory holds programs and data; the I/O interface connects external devices. All three work together during instruction execution.

Exam-ready summary

Q2: CPU executes and controls; memory stores programs/data; I/O interfaces connect peripherals. Data carries information, addresses specify locations, and control signals coordinate reads, writes, and execution.

Q5. Point-and-Draw Devices vs Graphics Tablets

Compare mouse/trackball devices with graphics digitizers or drawing tablets for coordinate tracking and pressure sensitivity.

🖱️

Mouse and trackball

Coordinate tracking

Usually relative movement: the pointer moves based on device motion. A trackball stays still while the user rotates its ball.

Pressure sensitivity

Usually no pen-pressure sensing; buttons and scroll wheel provide selection and navigation.

Best applications

Menus, object selection, general computer use, and many CAD operations.

✍️

Graphics tablet / digitizer

Coordinate tracking

Maps pen position on the tablet to a corresponding screen or drawing coordinate; many tablets use absolute positioning.

Pressure sensitivity

A pressure-sensitive stylus can vary line width, opacity, or brush response. Some devices also detect tilt.

Best applications

Digital illustration, handwriting, tracing, and precise freehand input; also useful for CAD markup.

For CAD

A mouse is practical for precise clicking, menus, and selecting objects. A tablet can be useful for sketching and annotation.

For digital art

A graphics tablet is usually better for natural strokes because supported pens can respond to pressure and sometimes tilt.

Important: not every digitizer supports pressure sensitivity, and the exact tracking method depends on the device and software.

Exam-ready summary

Q5: Mouse and trackball typically control a relative pointer and usually lack pressure sensing. A graphics tablet maps pen position to drawing coordinates and may support pressure or tilt, making it especially useful for digital art.

Q6. Choosing Equipment for Civil Engineering Blueprints

Assess a traditional drum/flatbed plotter against a UHD monitor plus large-format printer.

📐

Drum / flatbed plotter

Traditional pen plotters draw vector lines. Flatbed machines hold the sheet still; drum plotters move paper around a drum. They can make precise line drawings but may be slower and require specialized maintenance.

Specialized vector workflows
🖨️

UHD monitor + large-format printer

A high-resolution monitor helps inspect fine detail; the printer produces physical plans. Modern wide-format printers handle vector lines, text, fills, and raster images.

Versatile modern workflow
CriterionTraditional plotterMonitor + large-format printer
Line resolutionPrecise pen-drawn vectors; depends on pen and mediumCan produce crisp lines at suitable resolution with correct calibration, paper, and vector settings
ScalabilityLimited by machine bed/roll width and mechanicsDigital plans scale readily; final print size depends on printer width and media
Content typesBest for line drawingsHandles lines, text, shading, images, and colour layers
Long-term costMay involve specialist maintenance and consumablesVersatile and often easier to integrate; ink/toner, media, calibration, and maintenance remain ongoing costs
Recommendation: for most modern civil engineering offices, choose a calibrated high-resolution monitor with a professional large-format printer. It is more versatile for CAD and mixed-content plans. Confirm required line widths, print scale, archival media, and total cost per sheet before purchasing.

Exam-ready summary

Q6: For most modern civil engineering offices, a high-resolution monitor plus a professional large-format printer is more versatile and integrates well with CAD workflows. Actual line quality and lifetime cost depend on the printer, media, maintenance, and production volume.

Q7. Facial Recognition vs Voice Recognition

Critique biometric reliability and security in high-noise, publicly exposed environments.

👁️

Facial recognition

Reliability

Unaffected by ambient sound, but can fail with poor lighting, camera angle, occlusion, image quality, or appearance changes.

Security risks

Photos, video, or masks may fool weak systems. Public deployment also raises surveillance and privacy concerns.

Mitigations

Liveness and presentation-attack detection; test false acceptance/rejection across different users and conditions.

🎙️

Voice recognition

Reliability

Ambient noise, distance, echo, illness, and microphone quality can reduce accuracy.

Security risks

Recordings, replay attacks, voice cloning, and synthetic speech can compromise weak systems.

Mitigations

Noise suppression and anti-spoofing help, but public speech may expose biometric data to bystanders.

Assessment: neither biometric is infallible. In a noisy public space, voice recognition is especially affected by acoustic conditions; facial recognition avoids sound problems but still has lighting, spoofing, bias, and privacy risks. Prefer multi-factor authentication such as a secure card plus PIN, encryption, limited data retention, human review, and a non-biometric alternative.

Exam-ready summary

Q7: Voice recognition is especially vulnerable to noise; facial recognition is not noise-sensitive but can be affected by lighting, spoofing, bias, and privacy issues. Neither should be the sole security layer in an exposed public environment.

Q8. Accessible Hands-Free Computer Workstation

Design a workstation for a visually impaired user using non-visual input and specialized output devices.

🎤

Voice input

A noise-cancelling headset microphone and speech-recognition software support dictation, commands, searching, and hands-free navigation.

Primary hands-free control
⌨️

Tactile keyboard

A keyboard with raised home-row markers or braille labels supports touch typing when hands are available.

Tactile backup
🔊

Screen reader + speech

Screen-reader software announces menus, text, focus, errors, and status updates through a voice synthesizer and headphones.

Non-visual feedback
⠿

Refreshable Braille display

Optional tactile output presents on-screen text as Braille cells, useful for quiet work and accurate spelling or punctuation.

Tactile output
🧭

Accessible software

Use keyboard-accessible apps, labelled controls, clear focus order, shortcuts, accessible documents, and optional magnification/high contrast.

Compatibility matters
🛡️

Privacy and safety

Provide a physical mute button, confirmation before sending or deleting, secure sign-in, private audio, and adjustable speech rate/volume.

Speech is the primary input for hands-free use; tactile keyboard and Braille provide complementary alternatives when speech is inconvenient or inaccurate. Test the setup with the user and tailor it to their vision, hearing, motor access, language, and preferences.

Design principle: accessibility should be customizable. Keep essential functions operable without a mouse or visual confirmation, and offer a non-voice alternative for noisy or private situations.

Exam-ready summary

Q8: Use speech recognition as the main hands-free input, with screen-reader speech output for feedback. A tactile keyboard and optional refreshable Braille display provide complementary access, supported by accessible software, privacy controls, and user-specific setup.
